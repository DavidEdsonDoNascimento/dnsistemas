# Tarefa 001 — Substituição das imagens herdadas do template

## Objetivo

Substituir as duas imagens ainda herdadas do template original da landing page da Antero Sistemas.

O objetivo é eliminar a aparência de template e aproximar a identidade visual da marca Antero.

---

## Contexto

Site:

https://www.anterosistemas.com.br

Atualmente existem duas imagens provenientes do template original.

### Hero

Imagem atual:

`illustration-14.webp`

Problema:

Ilustração genérica de pessoas analisando dashboards.

---

### About

Imagem atual:

`about-square-8.webp`

Problema:

Foto genérica de reunião corporativa.

---

## Direção visual

A nova identidade deve transmitir:

- empresa de software
- desenvolvimento sob medida
- arquitetura de sistemas
- automação
- tecnologia premium
- empresa séria
- crescimento empresarial
- produtos digitais

Evitar:

- banco de imagens genérico
- pessoas comemorando
- reuniões clichês
- imagens muito coloridas
- visual infantil
- excesso de elementos

---

## Hero

Sugestões:

- arquitetura de software
- dashboards modernos
- automação
- fluxos digitais
- integração de sistemas
- visual premium
- tons neutros

---

## About

Sugestões:

- produto digital
- notebook
- planejamento
- estratégia
- tecnologia
- ambiente profissional

---

## Tarefa

Antes de implementar:

1. Localizar onde `illustration-14.webp` é utilizada.
2. Localizar onde `about-square-8.webp` é utilizada.
3. Identificar os componentes Hero e About.
4. Identificar onde ficam armazenadas as imagens do projeto.

Após isso apresentar:

- arquivos que serão modificados;
- arquivos que poderão ser removidos;
- nomes sugeridos para as novas imagens;
- ajustes necessários em `next/image`;
- ajustes de responsividade;
- critérios de aceite.

---

## Restrições

Não alterar:

- textos;
- layout;
- componentes;
- estrutura;
- espaçamentos.

Modificar apenas o necessário para substituir as imagens.

---

## Critérios de aceite

- Hero utiliza nova imagem.
- About utiliza nova imagem.
- Nenhuma imagem do template permanece.
- Layout permanece inalterado.
- Mobile continua funcionando.
- Build e lint continuam passando.

Após concluir a análise, aguardar aprovação antes de implementar.
